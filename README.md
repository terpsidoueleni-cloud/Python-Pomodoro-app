## Python Pomodoro Timer (Tkinter)

A simple desktop Pomodoro timer built with Python and Tkinter. 
This app helps you stay focused using the Pomodoro productivity technique.

## Pomodoro Technique

The timer follows the classic Pomodoro workflow:

25 min work → short break 
Every 4 sessions → long break 
Repeat

## Features 
Work / Short Break / Long Break cycles 
Visual countdown timer Checkmarks for completed work sessions 
Reset button Simple and clean GUI using Tkinter

## Technologies 
Python 3 
Tkinter (GUI)

## How to Run

Install Python (if not installed)

Check version:

python --version

Download the project or clone it:

git clone https://github.com/terpsidoueleni-cloud/Python-Pomodoro-app.git

Run the app:

python pomodoro-app.py
